## 2025-03-08 - [Optimize Duration Parsing without RegExp & Allocations]
**Learning:** `DurationUtils.parseDuration` is called frequently when rendering video duration tags, search result items, comments with timestamps, and player controls. The original implementation created `RegExp` objects, split strings into `List<String>`, mapped with `int.parse`, reversed lists, and calculated positional multipliers using floating-point `pow(60, i)`. Replacing this with a single-pass ASCII code loop using Horner's scheme eliminates allocation overhead and reduces runtime from $O(N \log N)$ regex/list operations to $O(N)$ with zero allocations ($O(1)$ memory).
**Action:** When parsing short structured strings (like durations, numbers, or time codes) in Flutter list renderers, use single-pass code unit loops rather than `RegExp.split` or `List.map`.
